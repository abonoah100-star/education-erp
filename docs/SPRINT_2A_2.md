# Sprint 2A.2 — Card Identity Quality

## الهدف
إغلاق ملاحظات جودة الكارت قبل الانتقال إلى ملفات الطلاب وأولياء الأمور.

## المنفذ
- اعتماد `Noto Kufi Arabic` كخط العرض الرئيسي داخل الكارت.
- تثبيت حزم الخط العربي داخل حاوية الـBackend وتحديث Fontconfig.
- محاذاة رقم الكارت في مركز الباركود هندسيًا.
- استبدال أرقام الكروت العشوائية بتسلسل ذري محفوظ في قاعدة البيانات.
- توليد الكود الداخلي تلقائيًا عند الإصدار أو ربط كارت من المخزون.
- إضافة رفع صورة JPG/PNG/WebP أثناء إصدار الكارت.
- معالجة الصورة وتوحيدها إلى صورة JPEG مربعة 720×720 قبل التخزين.
- تخزين الصورة في أصل وسائط مستقل داخل PostgreSQL مع إزالة التكرار عبر SHA-256.
- استخدام صورة طالب افتراضية عند عدم اختيار صورة بدل أحرف الاسم.
- نقل الصورة تلقائيًا عند استبدال الكارت.
- إضافة اختبارات لعقد التسلسل وجودة الرندر.

## قواعد الترقيم
- الطالب: `EDU-STU-000001` والكود الداخلي `STU-000001`.
- ولي الأمر: `EDU-GUA-000001` والكود الداخلي `GUA-000001`.
- المدرس: `EDU-TCH-000001` والكود الداخلي `TCH-000001`.
- الموظف: `EDU-STF-000001` والكود الداخلي `STF-000001`.

يتم تحديث العداد داخل Transaction في PostgreSQL لمنع التكرار عند تزامن الطلبات.

## ملفات قاعدة البيانات الجديدة
- `CardSequence`
- `CardPortraitAsset`
- الحقل `QrCard.portraitAssetId`

## معيار الاعتماد
- ظهور الخط الكوفي العربي داخل PNG النهائي.
- تمركز الكود أسفل الباركود.
- إصدار كارتين متتاليين بأرقام متتابعة دون تكرار.
- ظهور الصورة المختارة داخل الكارت.
- ظهور صورة الطالب الافتراضية عند عدم اختيار ملف.
- نجاح الطباعة والحفظ والمشاركة بالأوجه المختارة.
